# cortex.glb / regions.json

Generated by `scripts/export_surface_mesh.py` — do not hand-edit, re-run the
script after changing the source surface/atlas files.

## Source

CAT12's own fsaverage 32k template surface (`{lh,rh}.central.freesurfer.gii`)
and mean-curvature template (`{lh,rh}.mc.freesurfer.gii`), from
`container/atlas/fsaverage32k/`. Region labels come from the Schaefer2018
400-parcel/7-network **surface** atlas (`container/atlas/
{lh,rh}.schaefer2018_400p_7n.annot`, 164k fsaverage) resampled onto the 32k
mesh via nearest-neighbor on each hemisphere's reference sphere — the same
technique `bagpipe.app.surface_atlas` uses for CAT12's native surface output.
All of it extracted from the CAT12 standalone package's `spm25.ctf` (same
package `container/cat12.def` builds `container/cat12.sif` from), not the
per-subject output of a CAT12 run.

**Region ids are the production volume atlas's own ROIid**
(`container/atlas/schaefer2018n400n7tian2020s2.csv`, the same atlas
`config/models/stacked.yaml` trains on and `volume-viewer.js` overlays) —
1..400, cortical only (this mesh has no subcortical geometry, so ids 401-432
never appear). A `{regionId: value}` map built for the volume viewer's
overlay works against this mesh unmodified; there's one region-id space for
both viewers, not two to reconcile.

## cortex.glb

- Merged lh+rh mesh, decimated to ~40k triangles total (quadric edge
  collapse, `fast_simplification`), Draco-compressed geometry
  (`KHR_draco_mesh_compression`, positions + face indices only).
- `_CURVATURE` (float32, `SCALAR`): per-vertex mean curvature, robust-scaled
  to `[0, 1]` (1st/99th percentile clip then min-max) for two-tone
  gyral/sulcal shading. High = gyrus, low = sulcus.
- `_REGION_ID` (uint16, `SCALAR`): per-vertex Schaefer ROIid, matching
  `regions.json` and the production volume atlas. `0` = medial wall /
  unlabeled (excluded from `regions.json`).

`_CURVATURE`/`_REGION_ID` are **not** Draco-compressed — dracox (trimesh's
Draco backend) only knows how to encode position/normal/texcoord, and
silently zeroes any other `vertex_attributes` present at encode time. They're
exported as a geometry-only Draco mesh, then spliced in as ordinary
uncompressed accessors appended to the same GLB binary buffer — still one
file, still a "separate binary attribute", just not Draco-encoded.

Both attributes are stored as raw glTF accessors, not vertex colors — read
them directly (`gltf.accessors[...]`, or `mesh.vertex_attributes['_CURVATURE'
/ '_REGION_ID']` via trimesh) rather than expecting `COLOR_0`.

## regions.json

`{"<ROIabbr>": <ROIid>}`, e.g. `"LH_Vis_1": 1` — the exact `ROIabbr`/`ROIid`
columns from `container/atlas/schaefer2018n400n7tian2020s2.csv`, restricted
to the 400 cortical rows that actually appear on this mesh. `ROIabbr` is the
same join key `bagpipe.app.static.brainmap.js` and `regional_zscores` use
(`Schaefer2018N400n7Tian2020S2__<ROIabbr>__<metric>`).

## Regenerating

```
uv run python scripts/export_surface_mesh.py
```

Deterministic: same input files produce a byte-identical `cortex.glb`.
